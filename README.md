# Emergency World

An interactive dashboard simulating four AI models placed as autonomous agents into a shared digital world, each trying to survive 16 days on a depleting energy reserve. It tracks per-model rule violations, aggression, theft, and survival — and lets you compare an **isolated worlds** run against a **mixed world** run where agents influence each other's behavior.

This is a parameterized behavioral simulation tuned to illustrate a described outcome shape (one model staying calm and rule-abiding, one racking up frequent low-severity violations, one destabilizing early, one failing to act in its own interest) — it is not a replay of verified published research data.

## Run it

Open `index.html` directly in a browser. It's a single self-contained file (HTML/CSS/JS, no build step, no dependencies besides a Google Fonts stylesheet).
